# Journal repository template

What `oak bootstrap journal` writes into a new journal repository, beside the journal website from `templates/site/` (unless `--no-site`). With `--co-located` the repository also gets the paper launchers from `templates/paper/` and an empty `papers/`. This README is not copied.

- Setting up a journal: [Run a journal](https://scholar.nexus/oaktree-sapling/start/journal)
- Its settings: [journal.yml](https://scholar.nexus/oaktree-sapling/guide/journal-yml), [Branding](https://scholar.nexus/oaktree-sapling/guide/branding)
- The journal website: [Journal website](https://scholar.nexus/oaktree-sapling/guide/journal-site)
- What each file is for: [Files](https://scholar.nexus/oaktree-sapling/reference/files)
